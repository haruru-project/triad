# Triad

1つの質問を ChatGPT / Claude / Gemini に投げ、回答を1画面に集約して深堀りする PWA。

共有リレー（無料）と API（自動）をプロバイダ単位で切り替えられる**ハイブリッド構成**。
UI からは同じ「送信口」に見えるので、モードを変えても操作は変わらない。

## 構成

```
index.html            画面の骨格
styles.css            仮UI（設計フェーズで作り直す前提）
manifest.webmanifest  PWA定義 + share_target
sw.js                 Service Worker（共有の受け口だけを担当）
src/
  db.js               IndexedDB（SWとページの共有ストレージ）
  providers.js        3社の定義と送信アダプタ ← モードの分岐はここだけ
  prompt.js           深堀り／相互レビューのプロンプト生成
  app.js              状態管理とUI
```

## 2つの軸

設定は独立した2軸で構成されている。混同しないこと。

- **プロバイダごとのモード** … 手動 / API。3社それぞれ別々に切り替えられる
- **端末ごとの送受信方式** … 共有シート / コピー＋Webを開く。手動モードのときだけ効く

## 動作の流れ

### Android（送受信方式 = 共有シート）

1. 質問を入力（音声可）→「3社に聞く」でターンを作成
2. 各カードの「送る」→ 共有シート → 各社アプリ
3. アプリで回答が出たら、その回答を「共有」→ 一覧から **Triad** を選ぶ
4. Service Worker が `POST /share` を捕まえて IndexedDB に格納
5. 回答待ちが1つだけなら自動で割り当て。複数なら「誰の回答？」を選ぶ

### PC（送受信方式 = コピー＋Webを開く）

PC には共有シートも Share Target も無いので、戻す経路が構造的に違う。

1. 「開く ↗」= クリップボードにコピー **＋ プロンプトを URL に載せて相手先を開く**
   未送信が2社以上あれば「まとめて開く ↗」で1クリック
2. 相手先で送信（貼り付けは不要。URL から入力欄に入っている）
3. 回答をコピーして Triad のタブに戻る → **自動で取り込まれる**
4. 自動取り込みを切っている／権限が無い場合は「クリップボードから貼る」「手で貼る」

#### プロンプトをURLで渡せるか（実機確認: 2026-09-13）

| | `?q=` | ボタン表示 |
|---|---|---|
| ChatGPT | ○ 入力欄に入る（`?prompt=` に転送。送信は手動） | 開く ↗ |
| Claude | ○ 入力欄に入る（送信は手動） | 開く ↗ |
| Gemini | **× 無視される。パラメータごと捨てられ空の画面が開く** | コピーして開く ↗ |

Gemini だけ貼り付けが要るので、ボタンの文言とカード上の注記で区別している。
`promptParam` を null にすることでこの分岐が決まる。他社が対応をやめた場合もここを
null にすれば UI が追従する。

相互レビューのような長いプロンプト（エンコード後 1500 文字超）は URL 長の上限に当たるため、
対応社でも自動的にコピーのみへ落ちる。

「まとめて開く」ではクリップボードが1つしかないため、**URLで渡せない相手を最後にコピー**して、
貼り付けが必要な側の文面が残るようにしている。貼り付けが必要な相手が2社以上になった場合は
その旨をトーストで警告する（現状は Gemini のみなので発生しない）。

#### 自動取り込みの誤爆防止

戻ってきた瞬間にクリップボードを読むので、条件を絞ってある。

- コピー方式かつ設定が有効なときだけ
- 前回見た内容と違うとき（＝その間に何かコピーした）
- 送ったプロンプトのエコーでないとき（カードに理由を出して取り込まない）
- 宛先が一意に決まるとき（直近に開いた相手、または回答待ちが1つだけ）

取り込むとトーストに「取り消す」が出る。

既定は自動判定（Android 判定 + `navigator.share` の有無）。設定から明示的に上書きできる。
デスクトップ版 Chrome も `navigator.share` を持っているが、OS の共有シートに各社アプリは
並ばないので、capability 判定だけでは足りない。

## 設計上の制約（実測で確定したもの）

- **共有は1タップ1社**。`navigator.share()` は直前のユーザ操作がないと拒否される
  （transient activation）ため、await を挟んだ2社目以降は必ず失敗する。
  3社一括の自動送信は API モードでのみ可能。
- **Share Target は送信元を教えてくれない**。どのアプリから戻ったかは判別できないので、
  「回答待ちが1つだけなら自動割り当て」という運用で無操作化している。
  1社ずつ送って戻す使い方がいちばんタップ数が少ない。
- **`dialog` の close/cancel イベントは発火しない環境がある**（実測）。
  `runDialog()` は押されたボタンの click を一次情報にしている。ここを close 依存に
  戻すと、ダイアログを閉じても処理が進まなくなる。
- **Share Target は HTTPS + インストール済み PWA が条件**。localhost では検証できない。
  PC にはそもそも存在しないので、PC 側は常にコピー方式になる。

## デプロイ

静的ファイルのみ。ビルド不要。

1. どこかに HTTPS で置く（GitHub Pages / Cloudflare Pages のどちらも無料枠で足りる）
2. Android Chrome で開く → メニュー →「アプリをインストール」
3. インストール後、他アプリの共有メニューに「Triad」が出るようになる

## API モード

設定（⚙）で各社ごとに「共有 → API」へ切り替え、キーとモデルIDを入れる。

| 社 | キー発行元 | 備考 |
|---|---|---|
| Gemini | aistudio.google.com | **無料枠あり**。まずここだけ API 化するのが費用対効果が高い |
| Claude | console.anthropic.com | 従量課金のみ |
| ChatGPT | platform.openai.com | 従量課金のみ |

### モデルと価格（2026-09-13 に各社の公式価格表で確認）

1往復目は通常モデル、深堀りだけ上位モデルを使う。設定画面から変更可。

| 社 | 通常モデル | $/1M in・out | 深堀りモデル | $/1M in・out |
|---|---|---|---|---|
| ChatGPT | `gpt-5.6-terra` | 2 / 12 | `gpt-5.6-sol` | 4 / 20 |
| Claude | `claude-sonnet-5` | 2 / 10 | `claude-opus-5` | 5 / 25 |
| Gemini | `gemini-3.8-flash` | 0.75 / 3.75 | `gemini-3.1-pro-preview` | 2 / 12 |

注意点:

- **Gemini の Flash 系と 2.5 Pro には無料枠がある**。無料枠で収まる限り Gemini は 0 円。
  上限は AI Studio のダッシュボードでしか確認できない
- Gemini Flash の $0.75/$3.75 は **2026-12-31 までの価格**。以降は $1.50/$7.50 に戻る
- `gemini-3.1-pro-preview` は無料枠なし。無料で Pro 級が欲しければ `gemini-2.5-pro`
  （無料枠あり／有料 $1.25/$10）に替える
- OpenAI の新モデルは Chat Completions でも使える（Responses API 推奨だが必須ではない）
- 上位に `gpt-6-astra`（$10/$50）もあるが Opus 5 の倍。既定には入れていない

### 実測コスト（上記の既定・1往復 = 入力1,000/出力1,500）

```
ChatGPT  3.0円   Claude 2.6円   Gemini 1.0円   → 3社で 6.5円/往復
相互レビュー（入力3,000）3社で 7.9円/回
```

| 1日の質問数 | 月額の目安 |
|---|---|
| 10問 | 約3,600円 |
| 20問 | 約7,300円 |
| 30問 | 約10,900円 |

（各25%で深堀り1社＋相互レビュー1回を実行した場合。Gemini が無料枠に収まればこれより安い）

もっと下げたいなら通常モデルを `gemini-2.5-flash-lite`（無料枠あり）、`gpt-4o-mini`
（$0.15/$0.60）、`claude-haiku-4-5`（$1/$5）に替える。3社で約1.5円/往復まで落ちる。

### キーの置き場所

現状はこの端末の IndexedDB に平文で保存し、ブラウザから各社APIを直接叩いている。
個人の端末専用の割り切り。共有端末では使わないこと。

サーバ経由に移す場合、触るのは `providers.js` の `callXxx` 3関数だけで済むように
隔離してある。その際 Anthropic 向けの
`anthropic-dangerous-direct-browser-access` ヘッダは不要になるので消すこと。

この2点は実機で確認が必要。対応していない社は「手で貼る」で運用できる。
